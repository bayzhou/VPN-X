# VPN-X V1.5 · Windows 自动代理

VPN-X 是一款面向 Windows 10/11 的 Clash Verge Rev 自动代理工具。它适合有多个 VPN
厂商订阅、希望按偏好自动选择节点的人，也适合由一人维护目录、让多台电脑使用同一份
订阅和代理配置的场景。

- **集中维护订阅与配置。** 程序读取 `catalog-source.json`，按其中的链接下载
  并解密 VXP 目录。目录可以包含多个厂商的订阅链接和一套软件配置。管理者发布新版目录后，
  运行中的终端会按设定间隔检查更新，默认每 24 小时一次。
- **一键挑选可用节点。** 软件更新各厂商订阅，测试节点并准备备用节点，
  再按地区优先级、厂商优先级、订阅剩余流量和连接延迟排序。它逐个验证候选节点，找到可用连接后启用代理。
- **管理连接与查看进度。** 支持 TUN 虚拟网卡或 Windows 系统代理，以及规则或全局模式。
  可以跟踪启动进度、查看日志、手动选择节点，或在节点不可用时尝试下一个候选节点。
  重启会先关闭代理，再更新订阅并重新连接。
- **制作可分发的目录。** 在受密码保护的高级模式中，可以维护 VXP 链接和密钥，
  编辑厂商列表，并把当前软件配置和订阅一起导出为加密 VXP。

运行 `VPN-X-V1.5-Setup.exe` 安装，再从开始菜单打开 VPN-X，按提示授予管理员权限。
安装包已包含 Clash Verge Rev、Mihomo 和 7-Zip。用户设置和目录来源保存在
`%LOCALAPPDATA%\VPN-X`，软件更新不会覆盖已有配置值。启动时，安装包中的默认来源会补齐本机未设置的 VXP 来源和更新地址。从旧版便携包迁移时，可通过高级模式导入原来的 `catalog-source.json`。

## 首次使用

1. 安装后点击主页「一键启动」。软件先检查并启动内置内核，再同步订阅、测试和选择节点。安装包包含
   [Clash Verge 2.5.10 x64](https://github.com/clash-verge-rev/clash-verge-rev/releases/expanded_assets/v2.5.10)。
2. 软件从指定服务器下载并解密 `catalog.vxp`，应用软件配置并更新订阅。网络请求失败时最多重试两次。
   目录下载失败且没有可用缓存时，可以导入本地文件继续启动。
   如果链接和密钥尚未填写，请先在「高级模式」保存或导入目录来源。
3. 连接测试默认访问 ChatGPT 的公开地址，也可选择 Cloudflare 或填写自定义地址。
   连接测试以 HTTP 2xx 为成功。请至少填写一个优先地区，例如「香港，日本，新加坡」。
   从左到右优先级依次降低，软件按节点名称、常见简称或旗帜识别地区。设置项自动保存。
   回到「代理控制」点击「一键启动」。
4. 默认使用 **TUN 虚拟网卡 + 规则模式**。本机、内网，以及命中国内域名或 IP 规则的
   流量直连，其余流量走选定节点。公司域名或其他特殊地址可填写在设置的「自定义直连地址」，
   支持域名及其子域名（如 `*.office.example.com`）或单个 IP，多个地址用逗号分隔，修改后重启代理。
   这些例外仅保存在本机。Windows 系统代理会保留已有例外，再补充常见内网地址和自定义条目；
   只对遵循 Windows 代理设置的应用生效。全局模式会让进入内核的流量走选定节点，国内域名
   分流请使用规则模式。系统代理例外和 TUN 的内网 IP 排除仍在内核外生效。

## 更新、选优和日志

- 将新导出的 `.vxp` 上传并覆盖服务器同名文件后，运行中的终端默认每 24 小时检查并同步
  订阅和配置。下载、解析和对比期间不会停用代理或重载内核。没有变化就结束；有变化时先缓存，
  再提示「现在重启」或「稍后」。同一批变更只提示一次，选择稍后可通过主页「重启」应用。
  厂商增删以加密目录的名单为准；同一家厂商只在两侧都成功获取完整节点时比较。下载失败或恢复成功本身不算变更。
  应用已下载的订阅不会重新下载或全量测试节点，重启代理本身会短暂中断网络。
  本地导入的目录可以手动更新订阅；一键启动也会更新。远程目录失败时，
  一键启动可使用上次通过解密校验的目录，并在状态与日志中提示。
- 一键启动先测试各厂商首组的首选地区节点，按
  **地区优先级 → 厂商优先级 → 剩余流量降序 → 连接延迟升序** 排序。
  厂商优先级数字越小越优先，未填写的排在已填写之后。同一优先级再按剩余流量排名。
  流量读取订阅的 `subscription-userinfo` 响应头，缺失时显示「未知」。
  连接最优可用节点后，每家从通过测试的节点中保留最多两个备用。总备用不足两个时，才逐级扩展到已设置的下一地区，每个厂商每个地区随机抽测最多三个节点。首选地区无法连接时，也按这个顺序寻找可用出口。
  进度条分别显示当前阶段、已更新厂商数、已测节点数和候选验证进度。
- 主页标出使用中、备用和其他节点。双击节点会先测试，成功后再切换；测试失败保留当前出口。
  连接通过 HTTP 测试后显示「关闭」「切换为备用节点」「重启」。
  「关闭」结束 VPN-X 会话并恢复原有 Clash Verge 和 Windows 代理配置；
  自动故障切换和「切换为备用节点」都先按厂商优先级排列候选，再按地区、剩余流量和延迟排序，逐个复测。
  「重启」先关闭代理并恢复网络设置，再更新订阅和选优。
- 后台每 5 分钟检测当前节点，一次失败再试一次；连续两个周期均失败才尝试切换。
  每 10 分钟先在当前厂商和下一优先厂商的首选地区随机抽测，每家每个地区最多测 3 个、每家保留最多 2 个备用。
  不足 2 个时按地区优先级扩大到其他厂商。探测不修改代理选择；真正切换时，已有连接仍可能需要重连。
- 左侧「运行日志」单独显示最近 3000 条记录，包括已完成及正在执行的步骤、
  订阅错误、连接延迟、排序、逐节点验证和恢复过程。日志不会显示订阅链接或密钥。
- 启动时，同一地区的节点最多同时测试 12 个；补测备用时最多同时测试 4 个。实际切换出口仍逐个验证。
- 关闭窗口会收进系统托盘，代理与定时任务继续运行。要真正退出，请在托盘菜单选「关闭代理并退出」。
  强制结束进程或断电可能留下指向本地端口的 Windows 系统代理设置；再次启动 VPN-X 会尝试恢复上次会话。
- 「代理设置 → 检查更新」可以手动检查。配置了可信更新源时，程序运行期间每 24 小时自动检查并下载新版本。
  下载失败可重试；下载完成可立即更新或稍后处理。稍后选择不会安装，下次手动检查或次日自动检查时会再次提示。
  更新先验证签名、文件大小与 SHA-256，再使用内置 7-Zip 解压到独立目录。新版通过自检并启动后，
  才切换开始菜单的启动目标。旧版和用户设置保留。

- 左侧 Ask AI 打开 VPN-X AI 和本地使用指南。指南显示精简的实时状态，常见问题可离线回答。
  需要联网分析时，软件才发送问题、相关指南、精简状态和最近一轮对话给 DeepSeek。聊天每天最多 100 次，按本机日期刷新。

VPN-X 通常直接以管理员权限启动 Clash Verge 自带的 Mihomo 内核，
后台启动失败时会打开 Clash Verge 窗口。厂商订阅由 VPN-X 管理，代理组和选中节点会载入内核。
支持 YAML 中的内联节点、HTTPS 或内联 proxy-provider，以及常见代理协议。
会按代理组层级展开可选节点，采用 VPN-X 自己的分流规则。
Verge 的配置切换或内核重启可能结束运行中的 VPN-X 接管，此时重新一键启动即可。
后台内核通过带密钥的本机控制器接收指令，窗口模式通过 Windows 本机命名管道接收指令。
如果回退到 Clash Verge 窗口，其自身配置仍由 Clash Verge 保存到 Windows 应用数据目录。

## 目录格式与构建

「高级模式」默认进入密码为 `admin`。进入后可以维护目录来源、修改进入密码，以及填写厂商和 HTTPS
订阅链接来导出 `.vxp`。每家厂商可填写 1–999 的优先级，数字越小越优先。导出的加密文件包含当前的网络接入方式、
代理模式、优先地区、更新间隔及测试地址。

`catalog-source.json` 是独立的 UTF-8 JSON 文件，包含字符串字段 `url`、`key` 和可选的 `update_url`。
链接须为 HTTPS，密钥长度为 12 至 1024 个字符。高级模式可保存、导入或导出此文件。
`url` 是 VXP 下载地址，`key` 用于解密；`update_url` 指向已签名的 HTTPS 更新清单 JSON，
清单中指定 ZIP 下载地址。制作 `.vxp` 时使用高级模式输入框中的密钥。
这个 JSON 明文保存密钥，可交给需要使用该来源的终端。

`.vxp` 格式：7 字节魔数 `VPN-X\0\x01`、16 字节随机盐、12 字节随机 nonce，
随后为 AES-256-GCM 密文及 16 字节认证标签。认证附加数据为魔数。用 UTF-8 密钥字符串
经 scrypt（N=131072、r=8、p=1）派生 32 字节加密密钥。新版 UTF-8 JSON 包含
`vendors` 和 `settings`。厂商记录可包含可选的整数 `priority`。旧目录缺少此字段时视为未设置，
旧版仅有厂商数组的文件使用相同密钥时仍可导入。
导出和解密使用所配置的目录密钥。管理页密码只控制页面的进入权限。

在该目录下，用 64 位 Python 3.12、7-Zip 和 [Inno Setup](https://jrsoftware.org/inno-setup) 构建。安装器可选目录，目标须在本地磁盘上且普通用户不能写入；结束页可选择运行 VPN-X。

```powershell
python -m pip install -r requirements.txt pyinstaller
.\build.ps1 -OutputDirectory 'dist' -Installer 'C:\路径\Clash.Verge_2.5.10_x64-setup.exe' -SevenZip 'C:\Program Files\7-Zip\7z.exe' -ISCC 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe' -ChineseMessages 'C:\路径\ChineseSimplified.isl' -CatalogSource 'C:\路径\catalog-source.json'
```

构建生成首次安装所需的 `VPN-X-V1.5-Setup.exe`。配置更新公钥后可生成 `VPN-X-V1.5-Update.zip`。
安装包包含 7-Zip 命令行程序和许可，7-Zip 源码见 [官方仓库](https://github.com/ip7z/7zip)。
更新 ZIP 不带用户来源文件。要启用自建更新源，先生成 Ed25519 密钥对。私钥应单独保管，只将公钥内置到安装包：

```powershell
python sign_update.py keygen 'C:\签名\vpn-x-signing.pem' 'C:\签名\update-public-key.bin'
# 构建时加 -UpdatePublicKey 'C:\签名\update-public-key.bin' -UpdateUrl 'https://updates.example.com/vpn-x.json'
python sign_update.py sign 'C:\签名\vpn-x-signing.pem' 'dist\VPN-X-V1.5-Update.zip' 'https://updates.example.com/VPN-X-V1.5-Update.zip' 'dist\vpn-x.json'
```

先上传 ZIP，再发布清单。后续版本继续使用同一把签名密钥；如果未内置公钥，安装包可以正常安装运行，
但无法信任线上更新。
